# Task Tracker

Project: Task Tracker with User Accounts (React + Node/Express + MySQL/Sequelize)

## Tech Stack

Frontend:
- React
- Vite
- Axios
- Tailwind CSS
- React Router

Backend:
- Node.js
- Express.js
- Sequelize
- JWT
- bcrypt

Database:
- MySQL

## Features

- User registration and login
- JWT authentication
- Protected routes
- Category management
- Task CRUD
- Search
- Status filtering
- Category filtering
- Pagination
- User task isolation

## Local Setup

### Backend

cd backend
npm install
npm run dev

### Frontend

cd frontend
npm install
npm run dev
